# 語意路由矩陣

[英文版](routing-matrix.md)為權威版本。只需讀取相關路由與共通規則。下表是可重複執行的語意探測契約，並非產品指令；核准介接層必須依[介接契約](adapter-evidence-contract.zh-tw.md)提供可用的唯讀操作。缺少綁定時，確切探測與執行可用性為 `UNKNOWN`。

| 路由 | 唯讀探測 | 通過訊號 | 探測期間禁止 | 失敗處理 |
|---|---|---|---|---|
| C1 公開擷取 | 不帶工作階段憑證，擷取範圍內公開資源的最少內容。 | `public_retrieval`：當前成功回應含所需公開內容。 | 驗證登入、渲染互動、送出表單或私人資料。 | 擷取失敗為 `FAIL`；僅登入可讀的資源為 `NOT_APPLICABLE`，不可未授權轉用登入設定檔。 |
| C2 開發檢查 | 透過已連線檢查工具取得最少目標中繼資料與檢查能力。 | `inspection_connection`：即時目標中繼資料與所需檢查能力可用。 | 導航、執行頁面程式、擷取網路本文、cookies、插入監測或改設定。 | 回報確切傳輸／能力失敗；C3／C4 僅在全部條件與證據需求仍滿足時可替代。 |
| C3 工作階段自動化 | 透過控制器列出範圍內分頁／目標。 | `session_connection`：當前回應確認可控制的工作階段；`target_ready`：需要目標的操作已確認指定目標。空清單只證明傳輸，建立目標另需授權。 | 建分頁、導航、點擊、替換設定檔或啟動瀏覽器。 | 區分工作階段與目標；缺少必要目標阻擋任務準備。C4 仍須專案所有權。 |
| C4 專案測試 | 讀取專案身分、所有權、測試設定與依賴中繼資料。 | `project_ownership`：指定根目錄／設定／測試確認；`test_readiness`：宣告的依賴存在且核准測試路徑明確。 | 安裝依賴、初始化骨架、跑測試、啟動服務或寫 trace。 | 所有權不明為 `BLOCKED`；沒有專案自有瀏覽器測試為 `NOT_APPLICABLE`。靜態準備不代表測試執行或通過。 |
| C5 整合可見瀏覽器 | 檢查現行安裝整合資料，以核准唯讀方式連線，查詢可見性與指定分頁交接。 | `installed`：現行整合／client 已識別；`runnable`：當前主應用程式瀏覽器連線成功；`visible`：指定受控分頁出現在要求介面。 | 為探測而建立／開啟／顯示分頁、搶焦點、重啟、改快取或信任。 | 三關分開記錄；隱藏或交接缺失使 `visible` 失敗。執行受阻不否定安裝證據；其他介面不能滿足明確 C5 要求。 |
| C6 設定檔整合 | 查詢既有整合執行狀態與已去敏的設定檔／分頁身分。 | `integration_runtime`：即時整合握手；`profile_binding`：權威資料綁定已授權設定檔／工作階段與必要目標。 | 讀 cookie 值、啟用擴充功能、安裝 native host、複製或替換成空設定檔。 | 執行正常但缺綁定時，綁定為 `UNKNOWN` 並停止。未指定整合介面且保持相同設定檔條件時才可考慮 C7。 |
| C7 既有登入連線 | 驗證既有連線，再將去敏權威設定檔／工作階段身分與目標資料對照授權綁定。 | `endpoint_connection`：當前瀏覽器協定握手；`profile_binding`：指定既有設定檔／工作階段與目標確認；需要登入時，須有不敏感的驗證狀態證據。 | 啟動偵錯瀏覽器、改端點主機名稱或設定檔、登入、讀憑證、接受同意。 | 發現端點不代表連線，單獨握手不證明設定檔或登入。缺綁定即停止；登入畫面不授權換新瀏覽器。 |
| C8 遠端服務 | 在明確遠端範圍內執行已文件化、不變更狀態的能力／狀態查詢；必要時查核准遠端設定檔身分。 | `remote_scope`：授權涵蓋服務、資料與目標；`remote_readiness`：既有服務回應，所需核准遠端設定檔已綁定。 | 上傳本機檔案／工作階段、建設定檔或工作階段、配置資源、造成未核准費用。 | 缺遠端授權為 `BLOCKED`。只有變更狀態探測時，準備度維持 `UNKNOWN`，須另行授權；接受／排隊不代表執行。 |
| C9 本機 CLI | 查核准執行檔來源與已文件化、無副作用的可用性操作；唯讀確認既有目標。 | `cli_available`：當前 CLI 可呼叫；`target_ready`：指定目標可達。 | 套件啟動器自動安裝、啟動服務／瀏覽器、改設定或建立冒煙工作階段。 | 缺 CLI 阻擋 C9，替代須保留條件。說明／版本輸出只證明 CLI，不證明瀏覽器控制或應用行為。 |
| C10 桌面互動 | 查核准桌面執行狀態與不敏感介面資料；截圖及其可見內容皆在範圍內時才可檢視。 | `desktop_runtime`：即時互動介面存在；`desktop_scope`：目標與擷取／輸入範圍已授權。 | 點擊、按鍵、廣域桌面擷取、提升權限、繞過瀏覽器／登入檢查點。 | 缺執行環境為 `BLOCKED`；介面身分未明為 `UNKNOWN`。桌面控制不能滿足指定瀏覽器 API 證據契約。 |
| C11 擴充功能骨架 | 讀目標所有權／存在狀態與核准骨架指引。 | `scaffold_scope`：明確建立／治理要求及自有目標；`scaffold_readiness`：資源可用且不覆寫既有工作。 | 建檔、執行產生器、下載套件或覆寫非空目標。 | 無建立／治理要求為 `NOT_APPLICABLE`；所有權未明為 `BLOCKED`。預檢不自行授權寫檔，也不是擴充功能執行證據。 |

## 共通關卡規則

`PASS` 表示指定命題有直接當前證據；`FAIL` 表示已正確執行的探測提供相反證據；`BLOCKED` 表示授權、信任、安全或已知依賴缺失阻止前進；`UNKNOWN` 表示缺少、過時、模糊或未執行的證據；`NOT_APPLICABLE` 表示不適用，不能拿來豁免失敗的必要關卡。

權威身分來源無法取得時，綁定維持 `UNKNOWN`，不得只從端點、視窗標題或熟悉網址推定。狀態查詢若無法安全去敏，應阻擋而非讀取工作階段秘密。空中繼資料不能證明目標存在。

所有探測排除建立工作階段或付費資源的操作。如果環境只提供這類探測，須如實分類並使用另行授權的流程。逐關記錄觀察，不宣稱整體路由通過；任務開始前，全部適用必要關卡及硬性條件都必須滿足。
