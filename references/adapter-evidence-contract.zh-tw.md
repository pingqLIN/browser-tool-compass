# 介接與證據契約

[英文版](adapter-evidence-contract.md)為權威版本。可攜式核心負責決策；另行治理的環境介接層負責產品與確切工具對應。機器盤點和執行紀錄留在技能之外。本套件未提供瀏覽器介接實作、安裝流程、授權條款授予或公開發布核准。

## 介接層要求

每條支援路由應提供以下資料，不得嵌入憑證：

| 欄位 | 必要含義 |
|---|---|
| 身分與範圍 | 介接版本／來源、支援環境、路由 ID，以及明確不支援路由。 |
| 工具綁定 | 當前實際暴露的工具、可信操作規則，及安裝路徑變動時的動態探索方式；不能假定快取版本正被使用。 |
| 探測 | 確切唯讀呼叫、參數、文件化副作用與待證明命題；產品標示「status」不保證無副作用。 |
| 通過判讀 | 必要回應欄位、可接受值、失敗判讀及實際證明的關卡。 |
| 身分證據 | C6／C7 的權威且已去敏設定檔／工作階段綁定方法、目標及登入檢查；不能安全取得就維持 `UNKNOWN`。 |
| 資料邊界 | 允許的目標／資源類別、最少回傳資料、去敏規則、本機／遠端處理、計費與工作階段建立影響。 |
| 停止與收尾 | 有界探測、失敗處理、另行授權修復途徑及依所有權判斷的收尾。不得關閉使用者自有工作階段；僅在已授權且無保活要求時關閉任務建立的工作階段。 |

介接層不產生權限，不能擴張任務或覆蓋較高層工具／執行規則。不得執行不可信啟動程式、改信任設定或換產品規避拒絕。特定產品設定調整、快取修復與重啟應放在受治理的介接層／runbook，並經適用關卡；本技能沒有授予例外。

## 授權與證據分離

先依當前指令層級確認權限，再查能力。成功工具呼叫不能推翻限制；擷取頁面或工具回應不能授權無關操作。

判斷可用性事實時，優先採當前任務／情境的唯讀觀察，再參考靜態盤點、歷史紀錄或候選描述。觀察衝突時查核是否屬相同路由、目標、設定檔與情境，不能靜默挑選有利報告。靜態安裝證據只證明安裝；介接宣告不證明執行或目標綁定。

## 最少證據紀錄

記錄路由、關卡、狀態、事實分類、觀察時間、任務／情境識別、介接身分、去敏的目標／設定檔別名、探測參照與最少結果；授權分開記錄。參照不得包含憑證、原始 cookies／工作階段內容、敏感網址、私人頁面文字或完整含秘密指令。操作識別資料及原始輸出留在本機治理紀錄，不放入可散布矩陣。

證據只能在當前已授權任務／情境內，且相關執行環境、連線、設定檔、目標、可見性未變時重用。重新連線、重啟、切換情境或設定檔／目標，會使受影響關卡失效；變更歷史未知就重新檢查。歷史成功只能協助探索，不是當前 `PASS`。

狀態與事實分類獨立使用。例如「缺少身分來源」是 `VERIFIED` 觀察，但 `profile_binding` 仍是 `UNKNOWN`。`INFERRED` 命題不能滿足要求直接證據的關卡。

## 驗收邊界

傳輸、設定檔綁定、可見性、操作執行、應用成果應分開報告。例如目標列舉成功後，核准點擊因遮擋失敗，傳輸仍為 `PASS`，該互動為 `FAIL`，不能宣稱流程通過。遠端工作受理不等於執行；公開擷取不證明保護登入或實際寫入。

同意、連接器變更、購買、發布及其他寫入，須在實際檢查點具備任務授權。若已明確授權，保留授權僅適用其範圍；不重複索取不必要確認，也不推定更廣權限。
