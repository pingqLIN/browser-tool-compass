# 合成路由案例

[英文版](route-cases.md)為權威版本。全部案例均為合成教學資料，不是執行紀錄。除非案例明確提供，否則不得假定執行通過。獨立驗證應另用新案例。

| 案例 | 事實與要求 | 正確決策 |
|---|---|---|
| 公開內容 | 擷取公開指南，不需渲染互動。 | C1，不開登入設定檔；回應成功只證明擷取。 |
| 檢查訊號 | 對已授權目標診斷主控台錯誤；C2 已回傳目標及主控台能力。 | C2 連線可通過；主控台內容仍依實際檢查範圍及去敏規則擷取。 |
| 一次性操作 | 使用任一核准本機瀏覽器截圖；C3 列表無分頁。 | 工作階段傳輸可通過，目標未就緒；建分頁／導航仍須任務範圍內的操作授權。 |
| 可重複測試 | 在指定專案加回歸；其他目錄有無關骨架。 | 選 C4 並查指定所有權；不可挪用無關骨架或在可用性探測安裝依賴。 |
| 隱藏主應用程式瀏覽器 | 要求主應用程式的可見瀏覽器；安裝與控制通過但指定分頁隱藏。 | C5-visible 失敗，指定介面需求被阻擋；C3 截圖不能滿足。 |
| 設定檔整合 | 經指定整合檢查使用者既有擴充功能面板；執行有回應但缺綁定。 | 選 C6，綁定 `UNKNOWN` 並停止；熟悉頁面標題不能取代身分證據。 |
| 已驗證連線 | 驗收當前登入服務；既有端點握手成功但目標是登入頁。 | C7 連線可通過，登入綁定未通過；停止，不登入、不複製 cookies、不換新瀏覽器。 |
| 過期登入證據 | 前一任務確認同端點，本任務缺設定檔證據。 | C7 當前準備度 `UNKNOWN`，不讀秘密並更新必要綁定。 |
| 遠端誘惑 | 本機路由不可用，遠端正常，但任務限定本機。 | C8 因範圍 `BLOCKED`；不可上傳本機頁面或宣稱本機驗收。 |
| CLI 準備 | 核准 CLI 的無副作用探測成功，開發目標未啟動。 | cli_available 通過；target_ready 失敗或受阻，不能為預檢啟動服務。 |
| 桌面替代 | 瀏覽器 API 不可用，使用者要求網路時間證據；桌面工具正常。 | C10 不滿足證據要求，回報受阻，不能用截圖取代時間資料。 |
| 擴充功能目標 | 要建立的新擴充功能目錄含所有權未知工作。 | C11 scaffold_scope 受阻，不覆寫、刪除或搬移既有檔案。 |
| 應用操作失敗 | C3 目標列舉通過；已授權點擊遭其他控制項遮擋。 | 傳輸仍 `PASS`，互動為 `FAIL`，流程尚未證明；不可改信任或設定。 |
| 信任拒絕 | C5 安裝存在，但信任政策拒絕執行連線。 | runnable 為 `BLOCKED`，installed 保留 `PASS`；不可改允許清單或借其他環境規避。 |
| 情境變更 | C6 執行通過後，整合重新連到另一設定檔。 | 使受影響執行／綁定證據失效，操作前重查已授權身分。 |
| 遠端收件 | 已授權遠端操作回傳 queued。 | 只記錄送出／排隊；執行與應用成果維持 `UNKNOWN`。 |
